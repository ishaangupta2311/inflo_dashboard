Personal Dashboard Greeting

Replace the shared dashboard header label with a signed-in user greeting.

Behavior

The header displays Hi, {firstName} for every signed-in user, including staff. If Clerk does not provide a usable first name, it displays Hi there.

Data Source

Read the current user from Clerk on the existing server-rendered dashboard shell. No database change or client-side fetch is required.

Scope

Only the header title changes. Staff navigation, permissions, notifications, and client-facing page behavior remain unchanged.
